# VotoCiego · informe de datos

Comprobación: 2026-10-07.

Formaciones del índice del Senado, Podemos documentado en GP Mixto, coalición Sumar de 2023 y aportación propia de IU. Referencias de la XV legislatura, disuelta el 06/10/2026. No es un censo exhaustivo de afiliación individual de diputados.

Las elecciones del 29/11/2026 están convocadas por el RD 806/2026; las Cámaras de la XV legislatura están disueltas desde el 06/10/2026. El corpus reúne principalmente programas de 2023, páginas programáticas históricas y declaraciones de fechas distintas, **no un programa vigente de 2026**. No se han añadido candidatos: no se transforma un liderazgo en candidatura oficial.

- 0 propuestas huérfanas.

## Límites y decisiones editoriales

- La cobertura es incompleta: no es una auditoría exhaustiva de todos los miembros ni de toda actividad de la XV legislatura. El índice oficial del Senado identifica formaciones; no se transforma una lista de grupos en una lista de partidos ni se atribuyen escaños actuales tras la disolución. IU se incluye por su documento propio y relación electoral, sin afirmar una afiliación parlamentaria individual no comprobada. Otros componentes de Sumar constan como entidades relacionadas, sin heredar posiciones.
- Se buscaron medidas en el corpus y se revisó el contexto de los fragmentos incorporados; cada cita se comprueba literalmente contra su archivo de lectura. No se publica una postura por su ideología, por pertenencia a un grupo ni porque otra fuerza de la coalición la defienda. La disparidad de cobertura se hace visible, sin rellenar casillas para simular equilibrio. Se incorporan fuentes propias de Podemos, ASG, CC, Compromís, Más Madrid, AHI y Geroa Bai, y el programa de la campaña catalana de Junts+Puigdemont de 2024, conservando la atribución y la convocatoria. Las declaraciones locales o autonómicas conservan su ámbito y se comparan como condicionadas. Compromís-Sumar sigue con atribución conjunta, sin heredar posiciones a Compromís. Las enmiendas de ASG de 2018 se identifican como históricas. Las páginas oficiales leídas mediante fragmentos indexados se distinguen de las descargas completas, sin inventar hashes remotos.
- PSOE: el PDF completo procede de la web electoral España Avanza (pie PSOE–CEF, autor PDF PSOE), cotejado en título, contenido y paginación con la URL de psoe.es leída por consulta web. El navegador recibe CAPTCHA en la URL principal. VOX: alternativa oficial encontrada siguiendo “Descargar programa” en votaabascal.es; el enlace reducido de voxespana.es devuelve 404. Ninguno de esos accesos fallidos es una fuente activa del test. PP: el error de certificados del runtime Python se resolvió con curl del sistema, sin desactivar TLS.
- Fechas desconocidas se guardan nulas; no se convierte el nombre de carpeta de un servidor en fecha de publicación. La página es el contador PDF, incluida la portada, no necesariamente el número impreso. Hash SHA-256 de cada documento descargado y texto por página en research/text.
- Revisión editorial asistida, sin revisión humana externa independiente. El contexto plantea argumentos posibles, no efectos causales demostrados. Los controles automáticos comprueban procedencia, trazabilidad, vocabulario y referencias; no prueban por sí solos neutralidad política ni comprensión.
- Medidas relacionadas que no equivalen al enunciado permanecen visibles como contexto, pero sin coincidencia atribuida. Ejemplos: tipo mínimo efectivo de sociedades frente a bajar su tipo general; cuota cero por ingresos frente a primer año; gratuidad educativa frente a universalización; objetivos sobre PIB frente a renta nacional bruta.
- La jornada se compara por dirección, manteniendo explícitos límites diferentes. Las respuestas de acuerdo y totalmente de acuerdo no se usan para inventar intensidad de un partido. Neutral/incertidumbre y saltos no producen una coincidencia. Coincidencia parcial solo para condición o ámbito explícitos. El porcentaje de coincidencia usa únicamente preguntas con respuesta y evidencia comparables; no describe la afinidad con el programa completo.
- Devolución del proyecto conjunto de jornada/registro/desconexión en septiembre 2025: se registra la iniciativa de los grupos y el resultado conjunto; no se infiere oposición a cada medida. Se conserva actividad BNG de octubre 2025 junto a su programa, intervención de Noemí Santana (Podemos) en septiembre de 2025 y declaración de CC de julio de 2024, diferenciadas por tipo. UPN: el PDF oficial se recuperó posteriormente y se procesaron sus seis páginas. Compromís-Sumar: 13 páginas procesadas, dos medidas conservadas como contexto con atribución a la candidatura conjunta. No se ha identificado en este corpus una contradicción directamente comparable que permita completar una casilla: no se fabrica. Si aparecen orientaciones enfrentadas, el generador marca conflict y deja position=null conservando toda la historia.
- Actualización: npm run update-data verifica URLs y hashes, clasifica bloqueos, enlaces ausentes y cambios, y escribe un informe en src/data/pending. Nunca sustituye el corpus verificado. Revisión editorial y npm run generate-data son pasos independientes.

## Reproducibilidad

1. python3 scripts/expand-comparison.py importa de forma idempotente las decisiones revisadas en docs/comparison-evidence.json.
2. npm run verify-data comprueba uniones y fragmentos contra el texto extraído y los hashes locales.
3. npm run generate-data actualiza preguntas, trazabilidad y este informe a partir de issues/proposals/sources.
4. npm run update-data comprueba cambios externos sin modificar estos registros.
5. npm test, npm run test:e2e y npm run build.
